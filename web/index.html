Install in 2 minutes

  1. Download the APK above and open it. If Android asks, allow installing from your browser or Files app. If Play Protect shows a scan, tap Install anyway.
  2. Open GETDOWN Textrator and read the short note on how it uses your screen. Tick I agree.
  3. Allow display over other apps: tap the button in step 2, then switch on GETDOWN Textrator.
  4. Start the bubble. Android asks to allow screen capture. Choose Entire screen, then Start. You only do this when you switch the bubble on.
  5. Xiaomi, Oppo, Vivo, Realme: allow Autostart and set battery to No restrictions so the bubble doesn't vanish.

The Google Play version (coming soon) reads exact text without the screen-capture prompt.

Private by design

Text is read on your phone with Google's on-device text recognition. Screenshots are deleted right after reading, and they and the text you copy are never uploaded. We only collect anonymous counts (how many copies, from which app) to keep the service running. Read the privacy policy.
